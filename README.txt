SHRADDHA MEDICAL SHOP - CATEGORY HOVER VERSION

This version changes the product browsing experience:

Desktop:
- Customers see categories first.
- Hover a category to reveal only that category's products.
- Product rows include price and cart controls.

Mobile/tablet:
- Tap a category to open its products.
- Tap another category to switch.

The Firebase order/cart/tracking logic remains in app.js.

Files:
- index.html
- style.css
- app.js
- firebase-config.js
- pwa.js
- manifest.json
- service-worker.js

Do not change the Firebase config unless you are moving the website to another Firebase project.
